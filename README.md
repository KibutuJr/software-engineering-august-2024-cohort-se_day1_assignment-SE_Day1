List and briefly explain the phases of the Software Development Life Cycle.
- Planning entails defining the project's scope and goals.

- Requirement Analysis - Collect and record software requirements.

- Design - Create system architecture and user interface/user experience design.

- Implementation (coding) - Create software based on design specifications.

- Testing entails detecting and resolving bugs to assure quality.

- Deployment - refers to the release of software for use.

- Maintenance: Provide post-launch updates and repairs.

Compare and contrast the Waterfall and Agile methodologies. Provide examples of scenarios where each would be appropriate.
Waterfall Methodology.
Waterfall takes a linear and sequential method, with each phase (planning, design, development, testing, and deployment) completed before proceeding to the next. After the first criteria have been established, thorough documentation is required with minimum customer interaction. Changes are difficult to execute after a phase is done. Testing occurs after development.

Agile methodology.
Agile is an iterative and flexible methodology that allows for continual improvement through short cycles (sprints). It focuses on frequent customer collaboration and continuous testing throughout the development process. Agile responds to changing requirements, making it ideal for dynamic projects.

Key Differences:
Waterfall is inflexible and ideal for projects with established requirements (e.g., government systems, and building projects).
Agile is versatile and ideal for projects that require frequent changes (such as mobile apps and e-commerce platforms).
Waterfall testing occurs at the end of the project, whereas Agile testing is integrated into each sprint.
Appropriate scenarios for waterfall include healthcare systems, government contracts, and construction projects.
Agile: Mobile apps, game development, and e-commerce platforms.
Conclusion
Waterfall is great for organized, predictable projects, and Agile is ideal for fast-paced, dynamic development.

Describe the roles and responsibilities of a Software Developer, a Quality Assurance Engineer, and a Project Manager in a software engineering team.
- Software Developers create, test, and maintain code.

- Quality Assurance Engineer: Ensures that software satisfies quality requirements through testing.

- Project Manager - Responsible for project timetables, budgets, and team coordination.

Discuss the importance of Integrated Development Environments (IDEs) and Version Control Systems (VCS) in the software development process. Give examples of each.
- Integrated Development Environments (IDEs): Tools such as Visual Studio Code and IntelliJ improve coding efficiency through debugging and syntax highlighting.

- Version Control Systems (VCS): Tools like Git and GitHub help manage code changes and allow collaboration.

What are some common challenges faced by software engineers? Provide strategies to overcome these challenges.
Tight Deadlines - Use Agile methodologies and prioritize tasks.
Bug Management - Implement automated testing and continuous integration.
Keeping Up with Technology - Engage in continuous learning and attend industry conferences.

Explain the different types of testing (unit, integration, system, and acceptance) and their importance in software quality assurance.
Unit testing - the process of testing individual components.

Integration testing - ensures that modules work together.

System testing - encompasses the complete application.

Acceptance Testing - Ensures that software fulfills business requirements.
